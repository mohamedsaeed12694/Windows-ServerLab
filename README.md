# Windows Server Lab
A collection of Windows Server administration labs, configurations, migration, backup, and troubleshooting projects.
## Topics Covered
- Active Directory Domain Services (AD DS)
- DNS Configuration and Management
- DHCP Configuration and Management
- Group Policy (GPO)
- File Server Administration
- User and Group Management
- Windows Admin Center (WAC)
- FSMO Roles Transfer and Seizure
- Windows Server Backup and Restore
- Domain Controller Deployment
- Windows Server Troubleshooting
## Lab Activities
- Installing and Configuring Active Directory
- Creating and Managing Users and Groups
- Managing Group Policies
- Configuring DNS and DHCP Services
- Managing File Shares and Permissions
- Windows Admin Center (WAC) Administration
- Transferring FSMO Roles Between Domain Controllers
- Performing Backup and Recovery Using Windows Server Backup
- Troubleshooting Windows Server Issues
